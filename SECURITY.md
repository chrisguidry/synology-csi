# Security

Report a vulnerability privately through the repository's Security tab:
**Report a vulnerability** at
https://github.com/chrisguidry/synology-csi/security/advisories/new opens a
draft advisory that only the maintainers can read. Please do not open a
public issue or pull request for it.

You will hear back within 7 days. A confirmed vulnerability gets a fix on
`main` and a new image, and the advisory is published once the image is
out, within 90 days of the report. If a fix needs longer, the advisory says
why before then.

The `main` branch and the newest image on
`ghcr.io/chrisguidry/synology-csi` receive fixes. Older images do not.
